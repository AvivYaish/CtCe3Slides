# CtCe 2026 Slides

Slides for the 3rd CBER Crafting the Cryptoeconomy Conference, Columbia Engineering Innovation Hub, October 29–30, 2026.

## Layout

- One folder per day: `Day1_Thu_Oct29/`, `Day2_Fri_Oct30/`.
- One subfolder per session, prefixed with its program order and start time (e.g. `02_0900_Prediction-Markets-Research/`), so folders sort in program order.
- Each slide file is named by the presenter's last name, e.g. `Crane.pdf` or `Crane.pptx`.
- Each session's `README.md` lists its presenters and expected file names.
